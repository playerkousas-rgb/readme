# 🎨 STYLE PRESETS 規格（貼落現有產生器用）

> 檔名版號：v1.0 · © SCOUT SYSTEM · COPYRIGHT SCOUT SYSTEM
> 用途：畀現有 Type B 產生器（童軍漫畫生成器嗰類，見 [docs/16](../../docs/16-canvas-case-scout-comic.md)）加「風格 presets」，唔使新起一個 app。來源判決見 [docs/40 §2.2](../../docs/40-canvas-diy-candidates.md)；風格詞彙來源見 [docs/37 §4](../../docs/37-ai-tools-design-prompts.md)。
> 呢份係**規格同 prompt 骨架**，未貼入任何 app、未實跑過出圖；貼入嗰陣喺嗰個 app repo 做，唔好喺真理倉改模板當交付。

## 1. 點貼入去（最小改動）

喺產生器加一個風格 `<select>`（或者一排掣），揀咗就将下面對應嘅「風格句」加入嗰次出圖 prompt 尾段；再加一個「鎖定主體」開關，開咗就加 §3 嗰句。唔好為 presets 改產生器嘅注入／水印／紀錄邏輯（嗰啲係 app 本體嘅事，唔關 presets 事）。

## 3. 鎖定主體句（產品／標誌唔變形先加）

```text
產品／標誌本身嘅形狀、比例、標籤文字完全保持原樣，唔加唔改任何細節；只改背景、排版同光線。
```

收貨嗰陣逐隻字對標籤：AI 改錯字／捏造細節嗰張即棄，唔好攞嚟做真宣傳（[docs/37 §4.2](../../docs/37-ai-tools-design-prompts.md)）。

## 4. 紅線

- 成品一律 W1 可見頁尾＋W2 DCT 隱形水印，用解碼器驗到先出街（[docs/12](../../docs/12-copyright-scout-system.md)）。
- 民族／工藝風（青花瓷嗰類）借風唔借人哋圖案版權；用咗第三方參考就寫該 app repo 嘅 `CREDITS.md`（W8）。
- 人相（尤其成員）未經同意唔好攞去轉風格（A12，[docs/03](../../docs/03-security.md)）。
- 想留原圖／成品圖紀錄或者保密 prompt，先升 Type C（[docs/09 C6](../../docs/09-gemini-canvas.md)），唔好喺 Type B 硬加紀錄邏輯。
